# PR. PATH RESOLUTION CONTRACT
명시된 파일·폴더 경로를 찾을 수 없을 때의 공통 행동을 정의한다. Owner는 `controlplane/shared`이고 직접 Consumer는 `controlplane/AGENTS.MD`다.

## PR.1 TRIGGER

- 사용자 요청이나 제어 문서가 명시한 파일·폴더 경로를 Workspace 기준으로 확인했으나 존재하지 않으면 적용한다.
- 경로가 없으면 사용자가 해당 파일·폴더를 임의로 이동·이름 변경·삭제한 것으로 판단한다.
- 요청 자체가 새 경로 생성을 명시하거나 제어 문서가 Lazy 생성을 허용한 Output 경로에는 적용하지 않는다.

## PR.2 REQUIRED ACTION

1. 누락된 원래 경로와 경로가 필요한 작업을 확인한다.
2. 해당 경로에 의존하는 탐색·수정·생성·삭제를 중단한다.
3. 유사한 경로를 임의로 탐색·추정·대체하거나 기존 Reference를 자동 수정하지 않는다.
4. 사용자에게 누락된 경로를 알리고 변경된 현재 경로를 요청한다.
5. 사용자가 새 경로를 제공하면 그 경로의 `AGENTS.MD`를 포함한 Load 순서와 Owner를 다시 확인한 뒤 작업을 재개한다.

## PR.3 REQUEST FORMAT

사용자에게는 다음 정보만 간결히 전달한다.

- 찾을 수 없는 Workspace 상대경로
- 해당 경로가 필요한 이유
- 사용자가 지정할 변경된 현재 경로

누락 경로가 여러 개면 중복을 제거한 목록으로 한 번에 요청한다. 사용자 응답 전에는 해당 경로에 의존하지 않는 안전한 작업만 계속한다.
